# Rock, Paper, Scissors, Lizard, Spock

A command-line game written in Python where you play against the computer.
First to 3 points wins.

## How to run

Requires Python 3.10 or newer (the code uses `match`/`case`).

    python rpsls.py

## How to play

Enter a choice or its abbreviation:

| Choice   | Abbreviation |
|----------|--------------|
| rock     | r            |
| paper    | p            |
| scissors | sc           |
| lizard   | l            |
| spock    | sp           |

Rules: scissors cuts paper, paper covers rock, rock crushes lizard,
lizard poisons Spock, Spock smashes scissors, scissors decapitates lizard,
lizard eats paper, paper disproves Spock, Spock vaporises rock,
rock crushes scissors.

## What I practised

- Structuring a program into small functions
- Validating user input with loops
- Tracking game state (scores and replay)
